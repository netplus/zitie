# P9.4 高风险笔形与细笔名 · 40个字形、146幅原矢量图专家校对册（2026-10-28）

> **仅供专业审校，不是儿童正式字帖，也不代表笔序及细笔形已获权威批准。** 原v0.5.1、P9冻结校对PDF及正式 manifest 一律只读。

## 为什么追加一份专门图册

原P9校验已经可以证明201主字/1045个原正式版累计笔顺SVG/Form XObject剪裁被正确引用，却无法证明笔画的**真实几何起落、折钩衔接、细笔名和提示语**符合当下规范。P9.1逐条列出37个GF0023范围外特殊字形、14个原PDF只有“第N笔”占位名称的字（合计83笔），还有“子”第二笔细笔名与官方五码分类差异；人工逐笔审图时在260页大书中查找效率不高。

本图册按上述风险项合并去重：**37个范围外部件 + 14字欠细笔名（其中12字重合）+ 子字单独争议 = 40个主字**。对应旧字帖 **146个真实累计示范源矢量步骤**，其中不必重复收录其他201-40=161个原书主字。在原P9 260页审稿PDF上以Form XObject直接剪裁原图，按各原笔序逐幅放大排列，保留序号、旧源名称但在欠细名/子笔名位置明确改为“待核”，附字符、主ID、批次、原书来源、官方五码的适用范围以及两名审校人的留白格。

## 具体可验产物

- `scripts/build_cultural_p9_exception_stroke_atlas.py`：封面+40张A4逐字专页，4列×最多3行源图，**39mm源矢量笔画卡**（比整书31mm源图格更容易观察折勾），只放大既有P9真实PDF图，不使用AI绘制或重写笔顺。
- 每字标“**是否超出GF0023的8105字范围**”；范围内有原规范五码时保留官方PDF实际页及编码，范围外仅显示**第三方参考五码**，不假称已有GF3002完整原表。原1985年打印源和GF规范仍需分别审核。
- 欠细笔名的83步、子第2步，不从五码1/2/3/4/5自动猜横撇/竖钩/弯钩等细分名称；标“具体笔名待核”与“第二笔名称有争议”。
- `scripts/verify_cultural_p9_exception_stroke_atlas.py`：把**146个新图卡**逐一与原P9 260页同一源矢量剪裁的RGB渲染结果对照，以固定渲染倍率/归一尺寸限制最大误差；检查40个不同主ID、连续编号、41页A4、零误丢形。像素一致只是原书来源正确性证明，**不是国家规范正确性证明**。
- 41页全部渲染、四组十字风险接触画册、源PDF SHA256以及二次构建字节完全一致；产物仅可保留为 GitHub Actions **人工审稿附件**，不写成正式发行物。

## 尚需专家逐字完成

1. 37个非GF0023形体需新的适用原始规范、确切序列码、来源图形和一审二审（GF3002公开网络档案只有8页扫描节录，附表略去，不能使用“8页文件已取得”谎称20902字已逐项可核）。
2. 14个字83处需逐一看笔画几何、名称标准/教材原图，核实是否有源书笔形本身错误而不只是名称缺失。
3. **“子”原书第二笔“弯钩”与官方GF0023原码521之间矛盾**；后续P10校对母稿已仅隔离旧提示而未更改原图，本图册也只能作逐图判断不能提前写“竖钩已核准”。
4. 1045笔全部实际几何规范、P8 1013词音、P10 201幅专业插画与版权、P5纸质审稿、P6用户批准仍为正式新书不可跨越的阻断项。
