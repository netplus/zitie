## 版本约定

- `drafts/<version>/`保存已经交付或送审的阶段性PDF；新版本使用新路径，旧PDF不覆盖、不重新生成替换。
- `releases/<version>/`仅保存通过相应内容、版式和覆盖门槛的正式PDF；最终全书另需201主项和附形回归通过。
- `manifest.json`记录标题、批次、版本、页数、字节数、SHA256、源提交、复核记录和明确发布状态。
- 归档前检查PDF可打开、页数、A4尺寸和实际渲染；归档后CI验证二进制与清单一致。旧版内容状态按当时快照保留，不因新版复核而改写历史。
- 不把字体文件、私人会话或第三方出版物全文作为本书交付物上传。

v0.1.0三份PDF从既有构建产物恢复；合集和前言与此前会话交付文件逐字节相同。SHA256可由清单复核。
