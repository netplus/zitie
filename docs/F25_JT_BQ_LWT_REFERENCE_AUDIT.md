# F2.5 — 精确核对大写 J、T 与小写 b、q

**范围**：仅核对并必要时修改这四个拉丁印刷体字母及其复用到拼音声母的轨迹。该项目仍采用选定的 Learning Without Tears *print/manuscript* 教学法，并不构成全国统一的拼音笔顺标准。

## 独立权威原件

- **主要依据**：[Learning Without Tears，2018《Capital Formation Chart / Lowercase Formation Chart》](https://www.lwtears.com/sites/default/files/2022-01/English_print_letterCharts.pdf)：官方 PDF 第 **1 页**为大写 J、T；第 **2 页**为小写 b；第 **3 页**为小写 q。直接审读原页图中的起笔点、编号、箭头和动作。**不可仅按文字动作数推断提笔次数**。
- **出版方文字佐证**：[LWT 官方文章《How to Help Kids Fix Letter Reversals》](https://www.lwtears.com/blog/moving-forward-not-backward-reversals)：明确将小写 b 归入 Diver letters，连续进行下潜、沿原竖回上、向右绕圆。
- **图文交叉核对**：[The Language of Handwriting without Tears](https://imagineif.com.sg/wp-content/downloads/%E2%9C%85%20The%20Language%20of%20Handwriting%20without%20Tears.pdf)：以图解讲解大写 J、T 和小写 b、q 的起笔方向、连续动作及提笔。它是配套教学说明，不取代出版方原始官方 PDF。

## 原图可复核的书写动作（中文）

1. **大写 J**：右上竖向下；近底线转向左并略向上；提笔到顶端左侧；横向右。
2. **大写 T**：上端中央竖向下；提笔到左上；横向右。**本次不改轨迹**。
3. **小写 b**：顶端竖向下到底线；沿原竖线回到中格；越过圆顶、向右绕弧回到底线。**中途不能提笔，也不能对角穿越。**
4. **小写 q**：先 Magic c 左绕圆；右侧上返后垂直向下进入下格；底部弯向右上。**中途不能提笔，末端不得向左形成 g 样尾钩。**
