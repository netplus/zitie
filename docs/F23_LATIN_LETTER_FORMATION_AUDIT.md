# F2.3 — 拉丁字母与拼音书写顺序全面复核（选定教学体系）

**结论：以前的F1字母动画确实存在系统性方向/分笔错误。** 这并不是最终字形外观正确就可接受的问题。本文区分国家语言文字规定、教材出版方的教学法、原始工程矢量。纠错涉及26个大写+26个小写字母，因此同时影响汉语拼音声母、韵母及词语所重用的拉丁字母。

## 1. 证据来源和适用范围

1. 中国教育部：《[汉语拼音方案采用的字母跟英文采用的字母是相同的么？](https://www.moe.gov.cn/moe_879/moe_1252/s8447/201412/t20141204_179361.html)》。官方明确答复：拼音字母目前没有国家统一的笔顺标准，可参考拉丁字母书写习惯。**因此不应称这份F2.3矩阵为中国强制性拼音笔顺标准。**
2. **主要书写教学参考：** [Learning Without Tears (2018), Capital Formation Chart and Lowercase Formation Chart](https://www.lwtears.com/sites/default/files/2022-01/English_print_letterCharts.pdf)。此资料由该教育出版商自行发布，实际包含完整大写/小写字母的起点、箭头及笔画构成，适用于 print / manuscript 分笔而非连笔草书。
3. **交叉参考：** [Zaner-Bloser, Manuscript Handwriting Practice Pack](https://media.zaner-bloser.com/handwriting/pdfs/ZB_HW_Manuscript_Practice_Package.pdf) 及[官方教学样本](https://www.zaner-bloser.com/sites/default/files/image/samples/HW_K_NA_SP_TE_20255_WM.pdf)。两个体系在某些字母是否连续运笔或分笔上不完全一致。我们明确选用第2项作为统一模型，避免在同一播放器里混用不同出版商的相互矛盾教学动作。
4. 教育部关于[小学拼音采用字母字形](https://www.moe.gov.cn/moe_879/moe_1252/s8447/201412/t20141204_179278.html)的说明：考虑小学教学常用的单层 `a`、`g`。本工程延续此轮廓，不改成常见印刷字体的双层形状。

**授权与证据界限：** 我们阅读正版出版社公开的教学图，独立编写表示基本笔形的SVG中心线，**没有复制或再发布任何出版商的PDF图、原始字体或版权矢量**。下列每个动作是根据该书写教学方案的中文重述与自行建立的工程实现，不代表已经获得版权方授权或书法教师逐字签字验收。

## 2. 核对结论

以前使用简单SVG折线与分号来决定提笔。典型错误：

- 大写 `A` 从左下开始向上走，且只拆成2笔；参考教学法把向左下、向右下、中横分成3笔。
- 大写 `E` 从右上开始向左连写竖底横，只有2笔；应是左竖、上横、中横、下横4笔。
- 大写 `L` 把竖和底横连成1笔；参考方案两笔。
- 大写 `M`、`N` 将全部折线视为1笔，甚至在本应由上往下画的线段中向上逆写。
- 大写 `T` 原来先横后竖；参考方案先竖后横，虽都是2笔但方向有误。
- 小写 `d` 先写右长竖后补圆弧；参考方案先像 `c` 一样绕圆，再向上延展而后向下。
- 小写 `a`、`b`、`g`、`m`、`n`、`p`、`q`、`u` 被错误地拆分成多次起笔；选定方案用连续运笔组合，且不得简单把两条原路径合并为一条不连通路径。

原26大写中有13个字母与参考方案的笔数不同，原26小写中有12个不一致，合计**25个笔数差异**；即使笔数相同也不能据此证明方向正确，已逐一重审52个字母的起笔与路径方向。

## 5. 数据、动画与验收边界

- 数据层仍保持7类113个条目，原 `letters-0…25`、`initials-…` 等ID全部不变。修复的字母路径自然同步用于拼音声母/韵母/词语，不再另造一套互相矛盾的拼音运笔曲线。
- CSS四线三格坐标继续使用 `14/47/83/117`，沿用 F2.1 的470源路径全量几何守卫（修复后笔画计数会变化，应以重跑实际审计值为准）。
- 每个分号隔开的 SVG path 表示一次真正的 pen-down。连续笔画路径必须单段连接，无隐藏瞬移；动画一笔只到达已经发生的位置。起收笔必须和选定出版商方案的箭头保持一致。
- 新测试逐一锁住52个字母的预计笔数，测试特殊起点和相应书写方向，并确保拼音所有组合仍可形成完整笔画。
- 新数据不更改汉字部首/整字任何笔顺、正式 v0.5.1 299页 PDF、21批201汉字1045笔动画或已保存的学习者蓝墨轨迹。已有轨迹对应旧教学参考，其追溯/评分不应自动视为在新轨迹上获得通过。
- 未经真实 iPhone Edge 设备测试，不宣称该设备已经可以正常临摹；需同时检查 Chrome/Safari/iOS Edge。

## 6. 后续教学专家核验

教学出版社的示范本身包含其内部一致的教学选择，不等价于法律意义上的唯一笔顺。最终应结合目标学校实际使用的课本版本（英文印刷体与拼音字母形态可能不同），抽查疑义字母的入笔、连续性与四线三格占位，才能提升为"教学认可"状态。
