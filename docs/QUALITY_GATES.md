# 字段级证据与发布门槛

## 状态分开记录

`scope_status`：candidate / primary_table_checked / edition_verified。

`content_status`：pending / researching / primary_checked / cross_checked / blocked。

`artwork_status`：missing / acquired / matched。

`layout_status`：not_built / rendered / visually_checked。

`release_status`：draft / eligible / released。

取得PDF不是审读PDF；程序构建成功不是内容通过；一次复看不是独立双人复核。正式发布状态只允许在所有必需证据均到位后由审稿记录明确更新。

## 每条证据最小字段

source_id、原始出版物标识、版本、发布者、URL、所支持字段、原印页码与PDF物理页号或字条锚点、实际检查方式、检查时间、检查者、结论、局限。原件可访问时保存SHA256。多个转载使用同一publication_id去重。

证据字段包括：主部首身份/附形关系、字形、笔数、笔顺、细笔画名称、名称/拼音、位置变形、例字时序。不得把一个总的reviewed=true替代这些字段。

## 正式页的最低条件

1. 主项已对照选定版本的主部首表；变体已明确父项、位置及例字。
2. 对笔顺有大陆适用规范原件的逐字/逐部件直接依据；规范未列出的非成字部件，应保存相应规范部件资料及整字中的明确映射，不从同部首其他字猜测。
3. 有另一权威出版物或教材的相关字段交叉依据，明确其支持范围；需要第二份笔顺证据却未取得时不能用名称证据假装完成同一字段交叉复核。
4. 名称与细笔画名称已核对；疑点和地区差异已解决或在适用范围内作明确说明。
5. 逐笔图与证据一致，矢量顺序和笔数一致，部件提取不误切其他笔画；每一步和范字共用整体变换。
6. 每一页实际渲染并打开检查；数量、文字、红灰顺序、描写行数、页码均合格。
7. 记录复核者与方式；整书发布前未决冲突为零。

## 暂存与纠错

研究稿可以入库以保留过程，但须明示draft；默认正式构建必须拒绝不合格项。正文内容或笔画数据改动后，应使旧内容/矢量/版面验收失效并重新检查。来源更新不自动改变已发布页，先做差异审查与勘误。

## 印刷检查

A4纵向；常规练习4行×8格；第一行红字、第二行淡灰、后两行首格黑范字。复杂项分页。显示层级、印刷灰度与单色可读性需单独检查；格间箭头不是笔内运笔箭头。
