# 字段级证据与三阶段质量门槛

本文件同时约束阶段1内容覆盖、阶段2图形版式和阶段3归档发布。三个阶段必须分开计数，不能把后阶段未完成反向解释为内容没有进展，也不能把content_ready解释为release_eligible。

## 一、阶段1：内容门槛

阶段1使用：
- `content_status`：planned / in_progress / content_ready / blocked
- 每个字段另有自己的状态；允许单字段blocked而批次其它字段继续推进。

每个主项的内容层至少维护：
1. 主项ID与目标规范身份状态；
2. 结构前提；
3. 笔数、笔顺、细笔名；
4. 采用读音（适用时）；
5. 部首／部件名称；
6. 两条教学提示与自查句；
7. 整字语境与迁移边界；
8. 字段级来源、实际页码／字条、检查方式、结论和局限。

达到`content_ready`的最低条件：
- 已完成可独立核验字段的review/evidence入库；
- 教学文本不引用尚未核实的规范结论；
- 冲突和全书级未决有明确blocked/pending状态和解决路径；
- 不要求artwork、PDF、manifest或release已经完成。

GF0011—2022等全书共性来源未取得时，相关精确字段可保留pending；只要其它字段证据完整，就可以继续后续批次内容，不因一个全书级来源阻塞201项铺开。

## 二、证据最小字段

每条证据至少记录：
- source_id、publication_id、版本、发布者、URL；
- 支持字段；
- 原印页码与PDF物理页号或字条锚点；
- 实际检查方式、检查时间、检查者；
- 结论与局限；
- 原件字节可取得时保存SHA256。

多个转载使用同一publication_id去重；同文献镜像不算第二独立来源。

证据字段包括：主部首身份/附形关系、字形、笔数、笔顺、细笔画名称、名称/拼音、结构、位置变形、例字时序。不得把一个总的`reviewed=true`替代字段级状态。

## 三、阶段2：图形与版式门槛

阶段2使用：
- `artwork_status`：deferred / in_progress / artwork_ready
- `layout_status`：deferred / not_built / rendered / visually_checked

图形与版式最低条件：
1. 固定矢量来源和许可证信息明确；
2. 逐笔路径与已审笔数、笔顺、细笔名一致；
3. 当前笔红色、旧笔深灰，步骤号和笔名匹配；
4. 部件提取不误切其它笔画；整字/部件保持正确全局变换；
5. 实际PDF或页面渲染后逐页打开检查；
6. 数量、文字、红灰顺序、描写行数、页码、裁切、重叠均合格。

阶段2问题不阻止其它批次继续阶段1内容工作；内容发现错误时回写阶段1。

## 四、阶段3：归档与发布门槛

阶段3使用：
- `publication_status`：deferred / draft_archived / release_ready
- `release_status`：draft / eligible / released

每个实际送审/交付PDF必须：
1. 真实字节存入`deliverables/drafts/`或`deliverables/releases/`；
2. manifest登记pages、bytes、SHA256、真实source_commit、review_record；
3. 所有新增/修改页实际视觉检查；
4. 目标HEAD必要CI通过；
5. release前所有适用内容、图形、版式和全书级冲突门槛闭合。

Actions附件、外链或Base64文本不能替代仓库PDF。

## 五、正式页最低条件

正式页仍要求：
1. 主项已对照选定版本的主部首表；变体明确父项、位置及例字；
2. 笔顺有大陆适用规范原件的直接依据；
3. 相关字段有适当权威交叉证据并明确支持范围；
4. 名称和细笔名已核；疑点/地区差异已解决或明确限定；
5. 逐笔图与证据一致；
6. 每页实际渲染检查；
7. 复核方式有记录；整书release前未决冲突为零。

## 六、暂存与纠错

阶段1内容稿可以先入库，只要明确标记draft/in_progress。正文或证据改动应使相应字段的后续artwork/layout验收失效，但不应无关地回退其它已经独立闭合的内容字段。

阶段1原则上不为了一个批次频繁修改CI和生成脚本；工程重构集中到独立维护窗口。内容推进优先写`data/`、`reviews/`、`sources/`。

## 七、印刷检查

A4纵向；常规练习4行×8格；第一行红字、第二行淡灰、后两行首格黑范字。复杂项分页。显示层级、印刷灰度与单色可读性需单独检查；格间箭头不是笔内运笔箭头。
