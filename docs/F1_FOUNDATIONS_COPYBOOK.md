# F1 — 独立基础书写字帖（字母、数字、拼音）

**状态：工程练习预览；独立于正式汉字 PDF 的新增模块。**

## 1. 功能范围

- **英文字母**：A–Z 的 26 组大写与小写组合，共 52 个单独字母；
- **数字**：0–9 共 10 项；
- **声母**：小学常用教学分组 23 项 `b p m f d t n l g k h j q x zh ch sh r z c s y w`；
- **韵母**：6 个单韵母、9 个复韵母、9 个鼻韵母，24 项；
- **整体认读音节**：16 项；
- **四声示范**：6 组分别包含 4 个声调（含 `ǖ ǘ ǚ ǜ`）；
- **简单词语**：8 组（妈妈、爸爸、你好、谢谢、学习、书包、朋友、早上）。

共 **7 个类别、113 个可选练习项**。每一个印刷页包含“范字示范 / 浅灰描摹 / 空白独立书写”三行。

**入口**：`animation/foundations/index.html`，已有 `animation/book.html` 的首屏副标题提供链接。

## 2. 教学依据、界限与版式

汉语拼音的组成、拼写和声调依照教育部刊载的《汉语拼音方案》作为内容核对起点：
https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/195802/t19580201_186000.html

23 声母、24 韵母、16 整体认读音节为**小学课堂常用教学编组**，不应反向宣称《汉语拼音方案》原文逐项采用了同样的声母划分：方案的声母表与日常教学中的 y、w 归类有区别。

采用**四线三格**展示拉丁字母与拼音：顶部 14、中线 47、基线 83、下线 117（工程 SVG 单位），呈现大小写高度、上伸、下伸、声调。数字采用独立的**方格＋中心辅助线**。拼音使用单层 `a`、`g` 的自绘单线 SVG 路径，避免平台字体 `a/g` 的双层造型差异；`i` 加声调时去点，`ü` 的双点保留。没有随项目分发任何字体文件。

**重要边界**：路径与绘制顺序是独立手工编制的*工程笔迹示范*，没有来自指定小学课本或真实笔输入的逐笔走向标定。字母写法、占格、起收笔、数字笔顺、组合与例词还需要和目标版本教材逐项对照并由人工确认。页面不得提供“笔顺正确”的正式评分，任何浏览器几何检查均不能升格为教学校准。

## 3. 交互与存储

- 分类选择与前后导航、直接链接 `?group=finals&item=finals-5` 等；
- 默认 0.8× 的轨迹展示，允许暂停、重播和切换倍率；
- 点击/触屏直接书写蓝色轨迹：Pointer Events 适配触笔/鼠标，触屏事件作为 iOS 引擎后备；自然提笔形成一次实际笔迹；
- 不逐笔强制人工确认；撤销上一笔、直接清空整项，无二次确认框；
- 使用独立键名 `zitie-foundations-f1:<item>` 的浏览器 localStorage 保存归一化坐标；不上传、不写入正式 201 字汉字练习 IndexedDB，失败时提醒本机存储不可用；
- A4 打印当前类别的所有条目；打印对话框可选择另存 PDF。这是浏览器打印 PDF，而不是正式发布的固定 SHA 版本 PDF。

## 4. 与现有工程的隔离

**不修改**正式 `v0.5.1` 的 299 页 PDF、manifest、201 汉字 / 1045 笔规范数据、A3 毛笔运笔、笔压模型、原临摹存储与笔顺判别。只在 `animation/foundations/` 新增资源、从 `animation/book.html` 加只读链接，并在 Pages 工作流将这些资源打包。

## 5. 验收门槛

1. `node --test animation/foundations/f1.test.cjs`：覆盖分类数量、全部 SVG 路径、音调分解、i 去点和 ü 双点、离线交互约束；
2. `animation/foundations/browser-smoke.html`：实际 Chromium 加载后核对 113 项、深链、0.8×、动态 SVG、pen/touch 事件、自动本机存储/清空、A4 分类分页、页面不横向溢出；
3. 原 A1/Chromium + Book integrity CI 必须在**最终 PR HEAD** 同时通过；
4. 合并到 main 后，以**同一 merge SHA** 的 Pages Configure / Upload / Deploy 真正完成为上线依据。

待教学核验：字母字体习惯与书写方向、数字笔画动作、复韵母精确间隔、四线三格与真实 A4 纸张比例、正式 PDF 逐页视觉复核、iOS Edge/Chrome/Safari 实机临摹。现有 Chromium 测试不代表完成这些人工或设备验证。
