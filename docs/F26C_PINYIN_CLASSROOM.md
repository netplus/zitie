# F2.6c — 独立的小学汉语拼音运笔模型（首批）

**用户对象：一年级儿童。** 项目现在把英文字母的 **LWT Manuscript** 和中文小学课堂的 **Pinyin Classroom** 分开建模。两套都有四线格，但不共享声称“已核对”的提笔顺序。

## 教材依据与限度

- [人民教育出版社一年级上册教材官方目录](https://www.pep.com.cn/products/jc/jks/201608/t20160823_1369629.shtml)，确认 a o e、i u ü、b p m f、d t n l、g k h、j q x 等课程分类；**目录自身不包含本实现的逐笔坐标**。
- [人教一年级教师教学用书的网上转载](https://www.szxuexiao.com/keben/html/3597.html)明确：**a** 先左半圆，再竖右弯（两笔）；**u** 先竖右弯再竖（两笔），**ü** 是 u 两笔后另写两点（四笔）。这些说明按实际一年级课堂文本核对，非我方任意定义。
- [一年级 b p m f / d t n l 教学资源](https://zy.21cnjy.com/24790162)列出 b、p 各两笔，m 三笔，d、n 各两笔；[g k h 教学资源](https://zy.21cnjy.com/24790173)指出 g 为左半圆、竖左弯两笔。
- [一年级《j q x》教学案例](https://zy.21cnjy.com/26373298)：q 先左上半圆再向下写竖、两笔，与 LWT 英文小写 q 的一笔右 U 钩不同。
- [Learning Without Tears 英文字母图](https://www.lwtears.com/sites/default/files/2022-01/English_print_letterCharts.pdf)仍是**英文**字母的参考，不能在拼音中擅自引用它作为正式教学笔顺。教育部澄清目前**没有全国统一的汉语拼音笔顺国家标准**。

上述不少教学示例出自**公开的课堂教案或教师用书转载**，并非每一条都能直接在现行统编教材最新版原图中核验。明确保留“独立教学资料校核、正式教师终审尚未完成”的边界。

## 已有源模型和未完成项目

| 基础字母 | 英文 LWT / 旧模型 | 首批拼音课堂模型 | 占格 |
| --- | --- | --- | --- |
| a / ɑ | 英文一笔连写 | 左半圆 + 竖右弯，两笔 | 中格 |
| b、p | 英文一笔回竖接圆 | 先直竖，再右半圆，两笔 | b 上中格 / p 中下格 |
| d、q | 英文一笔 c 形再接长竖 | 先左半圆，再独立右竖，两笔 | d 上中格 / q 中下格 |
| g | 英文一笔 c 形接下伸钩 | 左半圆 + 竖左弯，两笔 | 中下格 |
| m、n | 英文一笔回笔连接两个或一个拱 | 首笔短竖、后续门洞：m 三笔、n 两笔 | 中格 |
| u | 英文一笔连续 U 弧 | 竖右弯 + 右竖，两笔 | 中格 |
| ü | 英文 u 一笔 + 两点 | 拼音 u 两笔 + 两点，四笔 | 上中格 |

页面已有其余拼音声母/韵母、整体认读和词语，凡**未列出独立的已来源映射**者，仍采用临时工程模型，并在提示中说明未逐项核对。下一轮继续处理 h/t/r/f 等，**当前不能将 113 项全部声称为教学审定通过。**

## 实现、兼容性与质量门槛

`data.js` 每个类别显式有 `script` 属性（`latin`、`numbers`、`pinyin`），`compose(text,kind,script)` 只对指定且有来源的拼音基本字母改用独立人工建模 SVG 轨迹。原来的 `compose(text)` API **仍走英文 Latin**，保护旧英文动画和测试。数码走 `squares`，不混用脚本。

应用的网页、实时动态 SVG、蓝色临摹覆盖层和 A4 分类打印都必须按**同一个类别 script** 组合。旧 `zitie-foundations-f1:<item>` key、`version:1`、笔迹归一化坐标保持不变；新增 `model` 和 `legacyInk` 记录来源。发现旧拼音笔迹，以及新版数字 1/4/8 对应的旧版本练习笔迹时显示兼容性提示，**不会静默删除或把旧笔迹冒充新版笔顺审核结果**。只有学习者主动“重新练习”才清除该项旧墨迹提示。

独立测试覆盖 9 种课堂字母笔数、ü和标调、英语模型不变、所有 113 项、含小写 b/q 的拼音页面、A4 打印和旧版笔迹恢复。新 SVG 路径为**我们原创的工程中线近似**，不复制出版社字体、图片或已发行 PDF。
