# F2.6a — 儿童入门书写质量：教材选型、字形工整度与来源审计

> **F2.6b 更新（2026-10-13）**：下面数字 1、4、8 的错误是 F2.6a 的历史缺陷基线，已经在 [F2.6b 教材核对与代码修正](F26B_NUMBER_FORMATION.md) 中逐项修复。当前线上源不再含这些旧动作，字母字距和小写 s 基线问题仍待解决。

> **性质**：正式实现前的可复核研究与度量基线；**不是**“现有字帖已获教学规范验收”。不从生成的 SVG 反向推导教材正确笔顺。

## 1. 研究对象

新基础字帖是给小学低年级儿童使用的拉丁字母、大写/小写、数字和拼音书写训练。评审不能仅检查单笔 SVG 是否可执行；还必须看是否**写得工整、可读、比例稳定、符合指定教学路径**。

现有版本：7 类 / 113 练习项；52 个 Latin 字母有各自的源矢量；数字 0–9 另有自绘路径；四线三格坐标 `top=14, middle=47, baseline=83, lower=117`，`height=132`。这些是**工程坐标**而非国家标准要求的数值。

## 3. 来源冲突必须明示，而不是掩盖

LWT 与 WETA/Reading Universe 都属于教育教学体系，但逐笔分组并不处处相同。大写 **T** 例如：LWT 原图先中心竖、再顶横；Reading Universe 原图首先顶部横线。项目**保留 LWT 为选定的书写教学动作体系**；第二套只做笔形清晰、占格和比例的横向评价。

同样，不应以英文笔顺单独决定小学汉语拼音（特别是 `ü` 及带调字母）的专用教法。需有显著来源标签。

## 4. 当前量化审计：可核验的具体缺陷

**4.1 固定字距不合比例。** 当前 `data.js / compose()` 不论字母宽窄，单字符均使用 `76` 个 SVG 单位。单线小写 `i` / `l` 的中心线水平跨度接近 `0`，`m` 为 `53`，`w` 为 `56`。在 `xièxie`、`shūbāo` 等拼音组合中，墨迹之间的疏密明显不均。**这是布局模型的问题，不是小写 i/l 字形必须拉宽。**

**风险：** 用户在旧 76 单位画布上已经存储了归一化蓝笔迹。若直接改成比例字距，旧记录坐标便不再与范字重合。因此光学校距必须进入**隔离预览 + 明确的记录版本/迁移方案**，不可悄悄在正式版本改 `compose()`。

**4.2 圆弧与基线偏差。** 小写普通字母的主体主要应落在 `middle=47 / baseline=83` 之间。当前 `s` 的 Bézier 实际 `maxY ≈ 87.3`，向下越出底线 **4.3** 个 SVG 单位；`e` 与 `u` 约为 `85.4`（**2.4** 越线）。是否需要微小曲线 overshoot 以显得光学整齐，是*工程字形判断*，并非教材指定“4.3 是否合格”的国标。首轮内部阈值建议 **基线±3 SVG单位**，只标记异常并人工比对出版社图，不盲目裁切。

**4.3 数字笔顺与首选教材存在明确冲突。** LWT 官方 PDF p4 的数字 `1` 为简洁的下行竖笔；当前自绘 `1` 含底横脚。教材的 `4` 从**左上方**行笔、向右经过中横、最后再写右侧长竖；现有 `4` 路径首先由**右下向右上**（`M52 83 V17`）。教材的 `8` 是一条连贯运动；现有实现将 `8` 画为**独立两个圆**。因此**数字的路径不能因为“构成一个正确外形”就被判定可用于儿童教学**。应将 0–9 的来源审核优先于字距审美调优。

**4.4 教学练习顺序。** LWT 和 Zaner-Bloser 都采用从直线/横线→圆弧→斜线等基础笔画逐步练习的分组，而当前 `letters` 只有 A–Z 顺序的选项。今后可增加不破坏 `letters-0..25` ID 的只读“相似笔画练习推荐”；不能重排现存 ID 导致恢复错误字母记录。

## 4.5 拼音与英文的书写分笔不能被一个共用 SVG 模型掩盖

进一步核对中文小学教材资料后，这成为**儿童教学正确性的独立阻断项**：

- [教育部网站刊载《汉语拼音的教学特色》（2018，原载《光明日报》）](https://www.moe.gov.cn/s78/A18/A18_ztzl/jnhypyfa/201805/t20180517_336341.html)明确指出，规范拼音书写的**占格位置、笔画书写不与英文字母混淆**；该文由北京育民小学的教育工作者撰写，是教学经验说明，而非新创国家强制性笔顺标准。
- [扬州大学提供的《小学语文课程与教学论》（第二版，教育科学出版社）](https://wxy.yzu.edu.cn/__local/0/1A/9F/593268E1EB9DFB1B08DA9992915_2DBDD149_8609C6.pdf)小学拼音教学案例中，`ɑ` **先写左半圆，再写竖右弯，两笔写成**。
- LWT 2018 官方图中的英文小写 `a` 是一条连续笔迹，因而**不能以这个英文一笔模型去给一年级拼音 `ɑ` 声称笔顺已合格**。
- 目前 `animation/foundations/data.js` 的 `compose()` 无论是 `letters`、`initials`、`finals`、`syllables`、`tones` 还是 `words`，都统一复用 `lower` 原始路径。**这属于需要独立课堂版本校核的模型设计，不应因为其渲染完整就继续默认教学正确。**

**F2.6b 设计修正：**分离 `LatinManuscript` 与 `PinyinClassroom` 源轨迹，包括 `ɑ/a`、`ɡ/g` 等易因字体而混淆的字形；逐项给原始课本证据、笔顺和四线三格占位。已有练习 `id` 及本机记录键不变；教学轨迹数据应有显式版本并处理旧轨迹兼容。变更之前**不应宣称现有拼音字帖笔顺是规范示范**。数字 1/4/8 纠正作为与该工作并行的下一优先级。
## 5. 质量分解与审查矩阵

| 维度 | 客观检查 | 需人工判断 |
| --- | --- | --- |
| 笔顺 Formation | 笔数、每笔起终点、连通性、局部切向方向与源图逐项引用 | 各出版商方案冲突及目标学校实际写法 |
| 字形 Shape | 竖画平行、横线水平、斜线角度、圆弧连续、无尖角/过长回钩 | 字体是否接近儿童课堂范字而非电脑印刷风格 |
| 尺寸 Size | 大写顶→基线、小写中线→基线、上伸下伸、数码笔画定位 | 视觉上的大小协调、笔画起收自然 |
| 字距 Spacing | 字形包围盒、侧边距、词/音节实际 ink gap、换行和A4重排 | 密度是否适合课堂描红、不同笔宽的错觉 |
| 倾角 Slant | 竖线偏角、斜线族一致性 | 当前首选竖直 manuscript 与小学实际习惯 |
| 数字 Number | 0–9 的逐项参考图、描摹、动态动画中笔尖和墨迹同步 | 指定学校是否采用不同 `1/4/8` 变体 |

## 6. 后续发布阶段与验收原则

- **F2.6a**：资料审查和可重复的全字符度量报告；不得宣称“现有字帖规范书写全部合格”。本阶段**不修改**正式字母、数字轨迹和旧练习记录。
- **F2.6b（优先）**：核对并修正 `0–9` 的笔顺；尤其数字 `1/4/8` 的来源偏差，按版本选择修正，保留单独参考证据和逐数字 QA。
- **F2.6c**：逐一重构字母工整度，重点关注小写 `s` 基线越界、字形体态和统一大小；每字要给前后视觉对比。
- **F2.6d**：字距优化在**隔离预览**验证；必须处理老版练习 `localStorage` 坐标空间和打印比例迁移，不能悄悄更改已有蓝笔迹。
- **F2.6e**：52 字母+10 数字逐项复核；全部 113 条目、移动触屏和 30 页 A4 实图、原 299 页 PDF 完整性及主项目 201 汉字/1045 笔必须继续验证。

儿童练字产品的最低发布原则：**正确性优先于动画华丽，来源可查优先于代码自证，字形工整优先于过分个性化的笔锋。** 所有量化容差均标记为项目工程建议，不冒充教育部硬性数字指标。
