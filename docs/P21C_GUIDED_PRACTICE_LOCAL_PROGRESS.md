# P2.1c — 逐笔人工确认、笔画撤销与 IndexedDB 本地恢复

设计依据：已核 Phase II PR #138、完成 P2.1a #140 / P2.1b #142，跟踪 Issue #143。状态：实施候选，必须通过全部 GitHub CI 后才可合并发布。

## 产品交付

- 在沉浸式田字格上沿淡红色当前笔画书写蓝色真实轨迹，**抬笔不会自动通过**；只有用户点击「确认这一笔」且原始触点具有有效行程，才按已审笔顺 n→n+1。
- 已确认的实际蓝色墨迹和原 PDF 同源参考轮廓同时显示；当前笔未确认/触控中断不能推进。支持“重写本笔”“撤销上一笔”“重新练习整字”，整字重练须二次确认。
- 水字四笔、龠17笔及全201字均由相同无硬编码状态机维护；最后一笔确认后呈现本人的整字笔迹与完成数量，**不承诺书法质量/正确性自动评分**。
- “上一笔参考／下一笔参考”仍可预览，但参考预览与已确认进度严格分离；在非当前待写笔预览期间禁用书写，必须返回当前笔后再写。
- 已确认笔画以 IndexedDB 记录，刷新/关闭后可恢复；草稿不写入数据库。按完整正式 PDF SHA256、该字 main_id 与 source SHA 复合键隔离，不跨字帖版本串联。
- 出现存储拒绝、配额不足时，界面明确提示“仅内存、退出会丢失”，不能伪称保存成功。保存中返回须等待异步写入结束，失败重新触发提示。退出时若有未确认草稿先请求确认。
- 整字重新练习需用户显式确认清除该字的本地记录；恶意/陈旧/缺字段的同键记录整体拒绝恢复，直到用户明确清除。

## 核心代码边界

| 模块 | 职责 |
| --- | --- |
| animation/practice/progress-controller.js | 纯状态机、来源哈希锁、严格当前 index、原始样点检验、用户确认/撤销/重新练习、只读快照与全部校验后一次恢复 |
| animation/practice/storage.js | 浏览器 IndexedDB 版本化库、按原 PDF/字形复合键隔离、顺序写入与删除、同会话旧 revision 不得覆盖新版本；无网络调用 |
| animation/practice/trace-canvas.js | 每笔单独重绘已确认真实蓝墨，当前 draft 增量绘画，DPR/窗口旋转后从实际采样点重新渲染；不自动替用户补源轮廓 |
| animation/practice/practice-bridge.js | 输入禁用/恢复、起始 local-load gate、按钮权限、临时草稿提示、写入失败降级、保存中退出等待与源播放器恢复 |
| animation/book.html / practice.css | 确认、撤销、重练、返回待写笔、本地状态、整字完成、二次确认；Pad/phone 继续保持大字格 |

本期不会修改正式 PDF、manifest、B01–B21、已发布源 SVG 和 medians、A3 原 StrokePlayer、front guard/动画节奏/压力模型；不引入远程存储、登录、云同步或外部运行时依赖。
