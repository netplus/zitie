# Phase II / P2.1 — 沉浸式逐笔引导临摹：交互需求与验收

状态：产品方向已确认（2026-10-12）；此文档为 **设计评审候选**，不是已完成的功能或教学效果认证。
跟踪：Issue #137；事实基线：main 2c4082ff66141aa5853dfd1c3dfa296810ed3523。

## 1. 产品目标、边界与默认决策

用户确认第二阶段采取 **逐笔引导**；目标终端包括 Web、iPadOS/iOS、Android Pad/Android 手机。
点击正式 A3.9 页面任意当前选中字的田字格，即进入以汉字书写为主体的沉浸式练习场景。在练习场景，学习者可以直接用手指或触控笔沿当前笔画书写；输入的真实轨迹随触点**立即**出现，直到提笔仍保留，而不是由程序自动替换为标准范字笔画。

- 默认逐笔模式：每一时刻只有一个“当前练习笔画”，顺序取正式 B01–B21 模型；不以自由画法/整字识别替换。
- 第一批目标：水（ID #77，4笔）贯通交互，然后全 201 字/1045笔使用同一个引擎。
- 保留正式 PDF v0.5.1 299 页、生成包、源 SVG 轮廓、medians、笔顺、A3.6 前缘守卫、A3.7 两档笔压、A3.9 主页面；不改字形，不把硬笔研究恢复为默认。
- **源轮廓/已核笔顺 ≠ 已核人体运笔中心线**：用于高亮和起收笔提示的 median 必须注明“工程参考，尚未经教师校准”；绝不能以其直接出具权威书写分数。
- 默认笔迹颜色为蓝墨色，源参考为灰色/淡红色；练习实际输入与原动画的红色源墨迹视觉区分清楚。
- 初期练习数据仅留设备本地；不登录、不上传、不对外发布个人轨迹或笔压。
- 本期“临摹”含笔画练习和按序完成，不承诺专业书法质量打分、AI纠姿、真人书写动力学重建、云端账号同步或 App Store 上架。

## 2. 用户故事与界面布局

### 2.1 进入 / 退出

- 正常浏览：学习者在 animation/book.html 选择“水”；播放或暂停的原笔顺动画继续可用。
- 点击田字格的可操作区域进入练习，另提供显式 **开始临摹** 按钮和键盘 Enter/Space 操作；无障碍提示不能只依赖“可点击的 SVG”。
- 进入时暂停原 StrokePlayer，保存当前 glyph ID、播放时间、速度、笔压风格；新练习层独立渲染，不从原 SVG DOM 偷移图形，也不改变 URL 当前 ID。
- 退出使用 **返回笔顺教学**；有尚未保存的新笔迹时提供“保留本地进度 / 放弃本次内容”选择，不能悄悄丢掉输入。关闭后原播放器还在原字/原时间点，默认保持暂停，不突然自动播放。
- 不依赖浏览器 requestFullscreen（移动 Safari/安装形态差异）；使用固定定位沉浸层，尊重动态视口高度和安全区。未来可增 PWA/原生容器的全屏能力，不改变书写业务 API。
- 浏览器后退 / Escape（仅适用键盘）、刷新、前后台切换均有清晰的退出、恢复或中断处理；不得绕过“放弃本次内容”确认。

### 2.2 沉浸式画面

横向平板：字格居中或偏左，占主要视觉权重；右侧窄栏放“第 n/N 笔”、提示及按钮。纵向平板与手机：字格居中，标题和当前笔信息在上方，简洁的主操作栏在下方。沉浸层不显示 201 字目录、长篇出处说明、PDF 练习列表及研究链接，但保留“查看书写来源/说明”的非侵入式入口。

布局目标：在可用区域内保持最大正方形字格，**不裁切字形、无横向滚动、主要书写操作与当前笔状态同屏**。尺寸由可视高度/宽度/安全区共同限制，而不是复制 A3.9 页面小字格的固定 410px 上限；横竖屏变化重新布局但不修改轨迹坐标。

### 2.3 字格视觉层级（自底向上）

1. 白色田字格与淡色十字定位线；
2. 与正式 PDF 同源的全部 stroke.outline：未到笔画浅灰、已完成笔画中性灰；当前笔画淡红高亮；
3. 可选的当前笔画起笔圆点、收笔参考和简短方向提示；它们由未教学审核的 median 推算，明确为“参考位置”；
4. 学习者的实际轨迹以高对比度蓝墨色覆盖参考层；未经确认的当前轨迹不能凭空补满源 outline；
5. 反馈浮层放在字格之外或不遮挡笔尖。指针/光标或触点提示不能盖住已写笔迹。

### 2.4 逐笔交互状态与操作

| 状态 | 学习者可见内容 | 输入与操作 | 状态转移 |
| --- | --- | --- | --- |
| TEACHING | 现有 A3 动画播放器 | 点田字格/开始临摹 | PRACTICE_READY |
| PRACTICE_READY | 字格放大、当前第1笔高亮、起笔参考点 | 手指/笔落在书写区；可返回教学 | DRAWING |
| DRAWING | 用户真实蓝色墨迹边写边显示 | pointermove 追加；pointerup 提笔；取消/旋转特殊处理 | STROKE_REVIEW 或 READY |
| STROKE_REVIEW | 刚写的轨迹完整保留、当前笔反馈与“确认此笔/重写” | 确认、重写、看单笔示范、返回 | READY(n+1) 或 READY(n) |
| PRACTICE_COMPLETE | 用户的全部实际笔迹 + 原字轮廓对照；不伪造评分 | 再练一次、撤销、返回教学 | READY(1) 或 TEACHING |
| INTERRUPTED | 被系统中断的当前笔不计入已完成 | 重写当前笔；恢复页面 | PRACTICE_READY |

**P2.1 第一个可发布竖切片**：先做到“落笔→实时绘制→提笔→保留当前轨迹→用户确认下一笔”，而不是立刻引入未校准的严格自动打分。只有完成并确认当前笔才能推进至下一笔；出现无有效行程、零长、越界异常等，温和提示“请重试”，仍可查看帮助。每笔单独保存，不能任意跳过而记为练成。提供“需要帮助→示范/跳过”时标记 assisted / skipped，结果页明确区分“完成练习”与“获得帮助”。

**P2.2 匹配阶段**（后续独立门槛）：高置信匹配可自动推进；低置信只提示重试；灰区保留轨迹并让学习者手动确认，不用单一严苛阈值惩罚笔法差异。源 median 尚未通过教学审核时，UI 使用“轨迹接近参考”而非“书写正确/错误”或分数。

### 2.5 主要按钮（始终可达）

- 返回教学；当前“水 · 第 n/4 笔”及已完成进度；
- 撤销上一笔（按笔画，不撤销半段后吞掉多笔）；重写当前笔；
- 看本笔示范（原有工程动画，仅作为学习参考；暂停输入，示范结束恢复）；
- 确认这一笔 / 下一笔（P2.1）、重新练习整字、完成后对照/返回。
- 清空整字必须明确二次确认；平板按钮建议触控面积至少约 44×44 CSS px，不能只有 12px 的图标点击区。
- 文字与颜色同时表达状态，不以红/绿颜色作为唯一对错信号。

## 3. 输入与异常语义

- Finger / pen / mouse 复用同一 Pointer Events 入口；mouse 是桌面验证/辅助输入。支持 pen/touch 优先；一笔仅允许一个 active pointerId。
- 书写区域使用 touch-action: none；其他操作区域保持正常滚动/点击和系统辅助缩放。笔压与倾角从能力检测结果采集；压力为 0.5 可能只是无传感器默认值，不应声称真实力度。
- 指针开始后用 pointer capture 处理离开字格边界的轨迹，仍对输入坐标进行合理的可视裁切；其他手指/误触不应给同一笔插入点或触发按钮。
- 有触控笔时可进入“优先手写笔”模式，屏蔽非当前触控；使用手指的学习者仍可明确改回“手指可写”。只依赖浏览器公开可用信息，不声称实现了系统级掌托识别。
- pointercancel、lostpointercapture、visibilitychange、横竖屏变换、页面返回必须结束捕获、标记当前笔 aborted，清除临时/预测墨迹，**不可误计为已完成笔画**。之前已确认的轨迹保留。
- 单笔可反方向写、脱离目标明显、在空白区乱画、画一半抬笔：实时输入先真实绘制，评判和提示仅在提笔后发生；初期保留手动确认/重试，而不是在写字过程中强行磁吸到范字。
- 中断、刷新或本地存储空间不足要有用户可见的回退信息，不因 storage 失败丢掉内存中的当前书写会话。

## 4. 统一验收用例

1. 点水字画布进入沉浸式练习，田字格显著大于 A3.9 教学小窗，第一笔高亮，页面操作区完整可见。
2. 在触屏/模拟 pointer 以非匀速连续书写：蓝色墨迹 **逐点跟随用户真实接触位置**，不会自动向前填涂成源字轮廓；笔离开后保留原笔迹。
3. 从第1笔完成并确认后只能进入第2笔；水四笔全部完成得到本人真实书写结果；撤销后回到正确笔序。
4. 零长落笔、第二根手指、手掌大面积触控、离开字格/返回、pointercancel、旋转、resize 和前后台切换均不得产生幽灵笔画、错误完成计数或丢失此前确认笔迹。
5. 同一物理手写轨迹在 390px 手机/900px 平板、横竖屏、DPR=1/2/3 下归一化坐标误差控制在设计精度范围，不因布局变化把书写点反转/镜像。
6. 浏览器回归覆盖水（含折钩）、一、口、月及龠17笔，再校验201/1045加载无缺笔；与原 PDF 的 SVG 相同，拒绝空数据/错误脚本组合。
7. 实机专项：至少 Safari iPad + Apple Pencil、Android Chrome/Android WebView + 主流触控笔、iPhone 手指，以及一台 Android 手机；系统掌托/手写笔压力支持以实测为准。
8. 完全不改变原 v0.5.1 PDF、B01–B21、manifest、ARPHICPL 许可、原 A3.6 的 2090 帧等正式 CI 回归。

## 5. 本期刻意不做

- 不把“模拟笔压版”的算法数值当成学习者真实压力；
- 不启用未教学审定的严苛分数/排行榜；不自动修正或重排原始笔顺；
- 不把安装到主屏幕的 PWA 说成 App Store / Google Play 原生上架；
- 不以截图视觉相似度代替真实连续触控、输入时序与掉帧测试；
- 不实现账号云同步、社区分享、上传儿童书写轨迹或远程 AI 批改。
