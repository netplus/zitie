# 15 mm 中号田字格练习版（独立候选，非正式 release）

## 需求与尺寸

用户反馈正式字帖的练字方格太大。已检查当前 `v0.5.1` 源：A4 每个常规练习页的 8×4 方格由 `(A4宽度−72pt−7×6pt)/8` 推得，物理边长 **21.2229 mm**。同类打印田字格并无对所有年级统一规定的单一边长；常见 12 / 15 / 18 / 20 mm 规格。这里采用中号 **15 mm** 作为打印临摹候选，并非自称国家强制标准。

- 纸张：A4 纵向、210×297 mm，打印缩放 **100% / 实际大小**，不要「适合纸张」。
- **实际练习区**：15×15 mm 方格，每行 **10 格**，4 行 **40 格**（从 8×4 的 32 格提升 25%）；格间距横向 6pt，纵向 16pt。
- 摹写顺序保持：第1行红色描红、第2行淡灰描字、第3、4行首字范例后独立练写。
- 「独立回忆」保留行间“先写/再写”提示；笔顺示范格、大字展示、拼音和辅助说明 **不缩小**。
- 墨色、字形、田字格虚线均从已归档 v0.5.1 的 **PDF 矢量**逐格裁剪等比复用，不更换字形资产、不拼接笔顺、不重排笔画。

## 工程事实与质量边界

**源 PDF 不动**：`deliverables/releases/v0.5.1/zitie-v0.5.1-A4.pdf` SHA256 为
`7fb6c7227258903828098c29368f0412a7b8621260d3d5f8ad91f45beba5eb90`，
动画 A3 继续引用该冻结源；新版只做另存候选，不更新正式版/manifest/动画数据。

运行：

```bash
python -m pip install PyMuPDF==1.26.7
python scripts/build_standard_practice_pdf.py
python scripts/verify_standard_practice_pdf.py
```

结果为 `deliverables/drafts/v0.5.2-15mm-rc1/zitie-v0.5.2-A4-15mm-candidate.pdf`。
其 `geometry.json` 记录每页的原格与新格坐标、SHA256、目标尺寸和分类，三个实际渲染的页面样张位于 `previews/`。

全书 **299页**；已处理 **268页描红/迁移教学练习+6页独立回忆**；其余 **25页**不触及；维持原 **238书签**及 PDF 页内链接。程序 fail-closed：输入文件 SHA、A4页数、旧格 32 个的尺寸/阵列位置、每页行距、布局容量或导航变化时即拒绝发布。新旧 PDF 不是字节一致，除格子以外的页面元素要求实际 PDF 渲染像素一致。

**未进行实物打印/教师验收**。请实际用 A4、100% 打印后用直尺检验任意格为 15×15 mm，并检查浅色线能否在打印机上区分、孩子用铅笔/钢笔时是否拥挤。未验收前保持独立候选，不宣称正式发布，也不替换网站当前正式 v0.5.1 链接。
