# 编写计划 v0.2：内容先行

编写对象：以大陆简体字教学为主要使用场景的儿童与辅导者。目标不是背诵一张部首表，而是看清笔画、掌握顺序、理解位置变化，最后能在整字中正确应用。

从2026-10-02起，工程分为三个阶段：
1. **阶段1：内容覆盖**——优先完成201个主部首的字段级内容与证据链。
2. **阶段2：图形与版式**——统一处理矢量、逐笔累计示范、A4版式和PDF视觉检查。
3. **阶段3：归档与发布**——统一处理draft归档、manifest、CI、release和全书终审。

详见`docs/CONTENT_FIRST_WORKFLOW.md`。当前默认处于阶段1。

## 一、范围与计数

主覆盖目标为《汉字部首表》2022年修订版的201个主部首。主索引、规范序号与教学顺序分离；教学可重排，规范身份不可悄悄替换。2022年发布说明确认保持原有201个主部首，附形有所调整；原件未取得的精确字段必须保留待核标记，不能用2009年内容冒充2022年原件。

阶段1允许在2022精确字段仍pending时继续核验其它独立字段，只要明确记录证据范围和未决项。**全书级来源阻塞不再阻止后续批次的内容编写。**

常用附形与位置变体另建表，归属于主项并指定使用位置和例字。它们不增加主部首完成数。独体字、左旁、字头、字底等需要不同写法时分别制图；同一个字形属于不同分析对象时保留说明。此前27项清单是重点回归集合，不等于全书范围，也不直接继承其核验结论。

“全量”指201主项全部有可核查的教学条目，以及本书明确承诺的附形／变体清单全部完成；不冒称穷尽所有汉字中的一切变体。

## 二、循序渐进的编排

全书采用两条检索路线：正文按学习难度和前置知识推进，附录按规范主部首序号索引。笔画数量只是难度的一项，连笔转折、相似形、位置变化和包围时序也决定先后。

1. 基础起步：少笔画、易辨认的主部首。
2. 常用迁移：由独体形进入左旁、字头、字底。
3. 比较辨析：成组比较相似部件。
4. 结构进阶：包围、半包围及穿插结构。
5. 扩展覆盖：较复杂或不常独立使用的主部首。
6. 综合复习：无编号回忆、整字迁移、易错项回看。

当前内容范围已经完成全量分批：**201/201主部首均已分配至B01—B21**，其中B01—B20各10项、B21为龠1项。完整批次清单以`data/batches.json`和`data/coverage.json`为准，不再只以B01—B05作为当前范围描述。

任何批次在阶段1的范围冻结或局部字段reviewed，都不表示GF0011—2022逐项身份、artwork或publication已经通过。

## 三、阶段1：内容覆盖

主项共21批：B01—B20各10项，B21为1项。单次运行常规推进20个不同主部首，即连续处理两个批次。

阶段1每批执行：
- **范围确定**：主项ID、教学字形、整字语境、直接相关变体线索。
- **材料定位**：来源版本、发布机构、实际页码／字条、镜像关系和可用哈希。
- **字段核验**：字形身份状态、结构、笔数、笔顺、细笔名、名称、读音、整字语境。
- **内容写作**：两条教学提示、自查句、迁移边界、易错项。
- **内容复核**：逐字段回到来源，记录冲突和未决项。

阶段1完成标准为`content_ready`。它只表示内容层可以进入阶段2，不要求当批已经有矢量、PDF、manifest或release。

在阶段1：
- 前一批artwork/PDF未完成，不阻塞下一批内容；
- 全书共性规范可持续采集；
- 有争议的单字段保留blocked，不拖住其它字段和下一批；
- 不频繁修改CI和生成脚本；工程重构集中处理，内容更新优先入库。

## 四、阶段2：图形与版式

阶段2集中处理：
- 固定矢量来源及许可证；
- 逐笔真实路径和已审规范原图对应；
- 当前笔红色、旧笔深灰、步骤号和细笔名；
- 描红／淡字／独立书写；
- 复杂字分页；
- PDF生成和所有新增／修改页的实际视觉检查。

内容发现错误时回写阶段1；纯图形问题不反向阻塞其它批次内容覆盖。

## 五、阶段3：归档与发布

阶段3处理：
- `deliverables/drafts/`阶段PDF；
- `deliverables/manifest.json`中的pages、bytes、SHA256、source_commit、review_record；
- 目标HEAD CI；
- `deliverables/releases/`正式稿；
- 201主项、附形／位置变体、原27项回归、目录／索引和全书逐页终审。

正式发布的要求不降低；阶段1只是改变推进顺序，不改变最终质量门槛。

## 六、状态模型

批次分别记录：
- `content_status`：planned → in_progress → content_ready
- `artwork_status`：deferred → in_progress → artwork_ready
- `publication_status`：deferred → draft_archived → release_ready

禁止再用一个超长状态字符串代表所有阶段完成度。旧字段暂时保留兼容，后续脚本重构再移除。

## 七、权限与持续接续

常规内容编写、核验、Issue、分支、PR和非破坏性合入由工程自行推进，不反复要求用户确认。仓库记录是跨会话接续入口。

当前阶段1的核心指标是：
- 内容范围覆盖数（当前201/201已分配）；
- content_ready主项数（当前30项）；
- 各字段pending／blocked数量；
- 来源和复核记录完整性；
- “evidence已入库但canonical/review尚未同步”的状态债数量。

阶段1后半程的主吞吐从批次建稿转向字段闭合，优先级依次为：已有证据状态同步 → 正式笔顺/细笔名 → 采用读音 → 结构与整字位置迁移；S03名称只处理尚未闭合的残余项。

PDF数量、artwork数量和release数量属于阶段2/3指标，不再作为阶段1继续下一批内容的前置条件。
