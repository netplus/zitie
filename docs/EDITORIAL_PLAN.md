# 编写计划 v0.1

编写对象：以大陆简体字教学为主要使用场景的儿童与辅导者。目标不是背诵一张部首表，而是看清笔画、掌握顺序、理解位置变化，最后能在整字中正确应用。

## 一、范围与计数

主覆盖目标为《汉字部首表》2022年修订版的201个主部首。主索引、规范序号与教学顺序分离；教学可重排，规范身份不可悄悄替换。2022年发布说明确认保持原有201个主部首，附形有所调整；原件未取得的内容必须保留版本待核标记，不能用2009年附件充当2022年原件。

常用附形与位置变体另建表，归属于主项并指定使用位置和例字。它们不增加主部首完成数。独体字、左旁、字头、字底等需要不同写法时分别制图；同一个字形属于不同分析对象时保留说明。此前27项清单是重点回归集合，不等于全书范围，也不直接继承其核验结论。

“全量”指201主项全部有可核查的教学条目，以及本书明确承诺的附形/变体清单全部完成；不冒称穷尽所有汉字中的一切变体。生僻、非成字或不能连续书写的部件不得删掉或用形近常用字替换；应降低练习负担并提供整字语境。

## 二、循序渐进的编排

全书采用两条检索路线：正文按学习难度和前置知识推进，附录按规范主部首序号索引。笔画数量只是难度的一项，连笔转折、相似形、位置变化和包围时序也决定先后。

1. 基础起步：少笔画、易辨认的主部首；认识横、竖、撇、捺、折、钩及田字格位置。
2. 常用迁移：由独体形进入左旁、字头、字底；重点说明变化的是笔形、顺序还是两者。
3. 比较辨析：成组比较相似部件；每次只加入少量新差异，穿插已学项。
4. 结构进阶：包围、半包围及穿插结构；用整字笔顺说明何时写内部、何时收框。
5. 扩展覆盖：较复杂或不常独立使用的主部首，保留识读和定位，不把每项都安排同等机械抄写量。
6. 综合复习：无编号回忆、整字迁移、易错项回看；不重复计算覆盖数。

第一批锁定10个主部首：一、十、人、八、大、工、土、口、山、巾。第二批锁定：水、火、木、日、月、田、目、手、牛、毛。第三批已冻结：刀、力、又、子、女、小、王、石、白、立，重点从简单独体字过渡到位置迁移意识。后续批次以覆盖表和前置关系排定，不以规范表的字形编码顺序代替学习顺序。附形可先展示迁移方向，未复核完成时不得出现为可描写的范字。

## 三、批次与工作阶段

主项共21批：B01—B20各10项，B21为1项。每批附带其直接相关的附形、例字和复习任务；附形页数不挤占主项数量。批次号不是章节号，最终章节可以汇集多个已完成批次。

每批执行：
- 范围冻结：选定主项ID、例字、位置变体和本批前置知识。
- 资料取得：保存来源版本、发布机构、原件/转载关系、页码或字条，以及可用文件哈希。
- 字段核验：核对形、音、笔数、顺序、细笔名、名称和整字语境；争议单独建Issue。
- 中间文稿：完成每项两条提示、自查句和复习设计；此阶段不是正式描红页。
- 图形匹配：每条真实笔画路径与核验顺序逐一对照；禁止把单笔独立居中或用整字变色冒充笔顺。
- 试排：沿用确认版式，复杂项分页；研究稿必须清晰标识，不能与正式稿混装。
- 初校：机器检查编号、笔数、范围、缺字、页码；实际逐页查看渲染图。
- 复核：回到来源再看易混笔、重排的路径和位置变体；记录执行者，避免虚构双人审核。
- 合入：PR记录本批内容、来源、差异、测试和未决项；更新进度，生成批次PDF。

原则是生成一批、复核一批、冻结一批。遇到被资料阻塞的条目，可推进下一批资料采集，但不得把上一批标为完成；终稿发布必须全部解除阻塞。

## 四、全书交付

封面与版本页 → 前言 → 使用说明与基础笔画导读 → 分阶段正文 → 分组复习 → 主部首索引 → 常用附形/位置变体索引 → 来源与逐项复核说明 → 勘误记录。

交付包括：整本A4 PDF、按学习阶段/批次拆分的PDF、需要时的单页打印包、可重建的数据与脚本、逐项复核记录、版本变更记录。具体页数由可读性决定，不把“201项”硬塞成“201页”。

## 五、完成标准

- 主部首身份核对：201/201；没有用附形冒充主项。
- 每个主项都有可追溯的内容与至少一个适当使用语境；非成字部首优先示例而非硬造拼音。
- 字段级依据完整；每项至少有适用规范及另一权威来源的相关交叉证据。来源支持范围逐条写明。
- 常用附形清单已冻结且全部复核；原27项重点集全部回归。
- 全部新笔红色、旧笔灰色，笔顺累积无遗漏；范字和练习字使用同一字形变换。
- 字体无缺字、所有页实际渲染验收；A4实际大小打印说明、目录和页码一致。
- 发布包不夹带未通过页、第三方商业全文、字体文件或私人信息。

## 六、权限与持续接续

常规编写、核验、Issue、分支、PR和非破坏性合入由工程自行推进，不反复要求用户确认。仓库记录是跨会话接续入口。GitHub工作流可持续执行机器检查和已授权的材料下载，但不会自动替代内容审读；没有正在运行的任务时，不声称会在会话结束后继续人工式编写。
