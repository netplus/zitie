# M3 v0.5.0首批范围与验收

更新：2026-10-08。五个功能包均已实现，完整299页v0.5.0-rc1已生成、冻结并登记候选归档，M3退出证据见`reviews/M3-candidate-freeze-20261008.md`；最终归档PR #69必须通过目标HEAD CI并合入后生效。Q1当前独立队列0/299，不等于正式发布。`data/m3_scope.json`保留生成输入时的实现快照，当前状态由post_release及freeze记录管理。

## 五个工作包

| 工作包 | 明确范围 | 验收 |
|---|---|---|
| F01 学生前言与易读提示 | 区分儿童说明与辅导者/来源审计说明；处理既有前言跨页孤行、技术标识断行，保留全部真实限制。 | 不改规范结论；前言无孤行/截断，技术信息移入可读的审计附录而非删除。 |
| F02 比较与回忆 | 六组：日/目、木/禾、刀/力、大/犬、人/八、白/自；每组一个对照页和一个回忆练习页。 | 沿用已核字形、笔顺及可用细笔名；回忆页不预填答案，答案定位到已核示范；不将新页计入201主项。 |
| F03 整字迁移 | 厂→原、门→们、瓦→瓶、辶→近、囗→国、匚→区，各一例。 | 原始完整整字时序与证据索引一致；国/区的非连续围框及近的时序不得拆成误导的独立连续书写。 |
| F04 新版配置与导航 | v0.5.0独立配置、版本声明、目录页码及PDF书签；当前字段统计与历史发布快照分开。 | 不复用旧版本标签；书签和目录跳到真实目标；新增页的数量/分类单独记录。 |
| F05 字段限制与生成集成 | `data/teaching-source-policy.json`及`verify_m2_closeout.py`检查接口先行，后接入M3生成器。 | 任一训练请求依赖未核字段时明确拒绝或有标签地降级；已核无关字段正常可用；伪造解除来源阻塞应测试失败。 |

上述页数是内容模块范围，整本总页数须实际构建后记录，不预估充作产物。复杂字继续分页，不缩小田字格；常规练习保持4行×8格、A4纵向、白底红灰黑、当前笔红色、此前笔深灰、每页最多6个累计步骤。

## 字段级限制

201项精确GF0011—2022身份仍阻塞，禁止称本版完成2022正式主形/附形/名称/编码核验，但不阻断已有依据的笔顺和练习。14项细笔名不用作细笔名问答，9项读音不强配拼音，2项迁移不新增已核迁移示范，28项名称/37项结构不作为对应问题的标准答案。集合重叠，按请求字段判定，不能把整个主部首无差别禁用。

词中语素读音的证据不能扩展成所有读音；32项既有教学附形候选继续如此标记，不改称正式附形。选题和source policy需机器校验，生成器集成前不能仅凭计划说已覆盖这些限制。

F01/F02沿用PR67成果，F03完整整字迁移、F04全模块配置/目录/书签、F05全模块字段限制已在本轮实现。五包完成5之外，本轮已完成真实候选冻结；下一步进行独立Q1。记录：`reviews/M3-migration-integration-20261008.md`。
